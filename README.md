# 🚗 RC카 술래잡기 (rc-car-tag)

> **요약** — ESP32 RC카 4대(추격차 1 + 도주차 3)로 하는 술래잡기입니다. 폰(Dabble 앱)으로 조종하고, 추격차 앞의 **자석**이 도주차 뒤의 **홀 센서(KY-024)**에 3~5cm까지 다가가면 잡힙니다. 차끼리 부딪히지 않는 게임입니다.
>

## 🎮 게임 규칙 (짧게)

- 추격차가 폰의 **START**를 누르면 4대 모두 3초 카운트다운 후 시작
- 추격차 자석이 도주차 뒤 센서에 **3~5cm** 안으로 오면 잡힘 → 두 차가 **동시에 멈춤**
  - 잡힌 도주차: 그 판 끝까지 못 움직임
  - 추격차: **1초 뒤** 다시 움직임
- 도주차가 **모두** 잡히면 게임 끝 → 추격차가 START를 다시 누르면 새 판
- 추격차는 앞의 물체를 초음파로 보고 3cm 앞에서 스스로 멈춤 (부딪히지 않게)

## 🛠 펌웨어 올리기 (조립 담당용)

VS Code + **PlatformIO** 확장을 씁니다. 4대 모두 **같은 펌웨어**이고, 차 번호·역할·보정값은 점검 프로그램으로 각 차 안에 저장합니다.

| PlatformIO 환경 | 언제 |
|---|---|
| `car1_test` | **먼저.** 점검 프로그램 — 배선·모터·센서 확인, 보정값 저장 |
| `esp32dev` | 점검이 끝나면. 본 프로그램 (게임) |

점검 프로그램은 시리얼 모니터(115200)에서 글자 하나를 입력해 씁니다. 순서:

```
p 배선 → m 모터 방향 → n 최소 출력 → d 주행 데모 → s 정지 시험
→ (도주차만) g 홀 센서 측정 → k 잡힘 기준 저장 (자석 5cm)
→ r 차 번호·역할 저장  (예: r 1 chaser / r 2 runner)
```

`?`를 입력하면 전체 명령이 나옵니다.
