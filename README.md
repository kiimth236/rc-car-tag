# 🚗 RC카 술래잡기 (rc-car-tag)

> **요약** — ESP32 RC카 4대(추격차 1 + 도주차 3)로 하는 술래잡기입니다. 폰 **브라우저**(앱 설치 없음)로 조종하고, 추격차 앞의 **자석**이 도주차 뒤의 **홀 센서(KY-024)**에 3~5cm까지 다가가면 잡힙니다. 차끼리 부딪히지 않는 게임입니다.
>
> 마감: **2026-12-06(일)** · 현재: 설계·배선 가이드·펌웨어 1차 완성, **실물 시험 전**

## 📱 폰으로 조종하기 (앱 설치 없음)

차 1대에 폰 1대입니다. 아이폰(Safari)과 안드로이드(Chrome) 모두 됩니다.

1. 차 전원을 켭니다.
2. 폰 Wi-Fi 목록에서 **`RCAR-번호`** 를 고릅니다. 비밀번호는 **`rcartag번호`** 입니다. (예: 2번 차 = `RCAR-2` / `rcartag2`)
3. 브라우저 주소창에 **`http://192.168.4.1`** 을 입력합니다.
4. 메뉴에서 **게임**, **혼자 놀기**, **이름 바꾸기** 중 하나를 고릅니다.

- **안드로이드:** "인터넷 없음 — 연결 유지"가 나오면 **연결 유지**를 고르세요. 그래도 페이지가 안 열리면 **모바일 데이터를 끄세요.**
- 화면은 옛날 게임기처럼 생겼습니다. 위쪽 작은 화면에 남은 시간·남은 차·내 차 상태가 나오고, 조이스틱과 SELECT·START 버튼이 있으며, 맨 아래에 `RC-CAR TAG · 이름 역할`이 보입니다.
- 폰 연결이 끊기면 차는 약 0.5초 안에 멈춥니다.
- 스티커(`docs/rc-car-stickers.html`)를 인쇄해 차에 붙여 두면 번호·비밀번호를 바로 볼 수 있습니다.

## 🎮 게임 규칙 (짧게)

- 추격차가 **게임 시간**(1:00~5:00, 30초 단위, 처음은 3:00)과 **참가할 도주차**를 고르고 **START**를 누르면 3초 카운트다운 후 시작
- 추격차 자석이 도주차 뒤 센서에 **3~5cm** 안으로 오면 잡힘 → 두 차가 **동시에 멈춤**
  - 잡힌 도주차: 그 판 끝까지 못 움직임
  - 추격차: **1초 뒤** 다시 움직임
- **참가한 도주차가 시간 안에 모두 잡히면 추격팀 우승**, 시간이 끝났는데 한 대라도 살아 있으면 **도주팀 우승** → 추격차가 START를 다시 누르면 새 판
- 참가하지 않은 차는 그 판이 끝날 때까지 **관전**(조종 잠김). 단, **혼자 놀기** 중인 차는 계속 혼자 운전합니다.
- 폰 연결이 끊긴 차는 멈추지만 잡힌 것은 아닙니다. 그동안 추격차가 다가오면 잡힙니다.
- 도주차 전원이 꺼져도 **10초 안에** 다시 켜면 살아서 돌아오고, 10초를 넘기면 잡힌 것으로 칩니다.
- 이름은 최대 2글자(한글·영어·숫자), **이름 바꾸기** 메뉴에서 바꾸며 모든 폰에 보입니다.
- 추격차는 앞의 물체를 초음파로 보고 3cm 앞에서 스스로 멈춤 (부딪히지 않게)

## 🛠 펌웨어 올리기 (조립 담당용)

VS Code + **PlatformIO** 확장을 씁니다. 4대 모두 **같은 펌웨어**이고, 차 번호·역할·보정값은 점검 프로그램으로 각 차 안에 저장합니다.

| PlatformIO 환경 | 언제 |
|---|---|
| `car1_test` | **먼저.** 점검 프로그램 — 배선·모터·센서 확인, 보정값 저장 |
| `esp32dev` | 점검이 끝나면. 본 프로그램 (게임) |

점검 프로그램은 시리얼 모니터(115200)에서 글자 하나를 입력해 씁니다. 순서:

```
p 배선 → m 모터 방향 → n 최소 출력 → d 주행 데모 → s 정지 시험
→ (도주차만) g 홀 센서 측정 → k 잡힘 기준 저장 (자석 5cm)
→ r 차 번호·역할 저장  (예: r 1 chaser / r 2 runner)
```

`?`를 입력하면 전체 명령이 나옵니다.
