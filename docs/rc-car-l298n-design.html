2. 목표와 성공 기준

요약 — 4대가 같은 펌웨어로 돌고, 폰으로 조종하고, 추격차가 도주차 뒤 3~5cm까지 다가가면 부딪치지 않고 "잡힘"이 되면 성공입니다. 마감은 2026-12-06(일)입니다.
  1. 4대 모두 같은 펌웨어 파일. 차 번호·역할은 NVS 설정으로만 다름.
  2. 폰(Dabble)으로 전진·후진·회전이 부드럽게 됨. 출발·방향 전환 때 ESP32가 재부팅되지 않음.
  3. 추격차 자석이 도주차 뒤 센서에서 3~5cm 안에 들어오면 잡힘. 6cm 이상에서는 잡히지 않음.
  4. 잡히면 두 차가 0.1초 안에 함께 멈춤. 도주차는 그 판이 끝날 때까지 정지, 추격차는 1초 뒤 다시 주행.
  5. 도주차가 모두 잡히면 끝나고, 추격차 START로 다시 시작.
  6. 추격차가 앞의 물체(도주차 포함)와 부딪치지 않음 (초음파 제한).

새 부품

부품수량달 곳 · 연결
KY-024 홀 센서 모듈 (49E 계열 + LM393)5 (도주차 3 + 예비 2)도주차 뒤쪽 끝 가운데. 센서 칩의 글자 면이 뒤를 향하게 세움. + → 3.3V, G → GND, A0 → GPIO36, D0 연결 안 함
네오디뮴 원형 자석 지름 20mm × 두께 10mm, N42 이상1 + 예비 1~2추격차 앞범퍼 끝 가운데. 평평한 면이 앞을 향하게. 높이는 도주차 센서와 같게
⚠ KY-024는 3.3V로 켭니다. 5V로 켜면 A0가 3.3V를 넘을 수 있습니다 (ESP32 핀 최대 3.3V).
자석 크기의 근거: 원형 자석의 축 위 자기장을 계산하면(N42, Br ≈ 1.3T) 10×5mm는 5cm에서 약 5G로 너무 약하고, 20×10mm는 5cm에서 약 38G(4cm 약 70G, 3cm 약 140G)입니다. KY-024를 3.3V로 켜면 약 0.9mV/G이고, 평균을 내면 ESP32 ADC 흔들림은 수 mV 수준이므로 약 20G 이상이면 구분됩니다. 실제 값은 시험으로 정합니다 (10장).
⚠ 큰 네오디뮴 자석: 서로 붙을 때 손가락이 끼일 수 있음 · 쉽게 깨짐 · 하나씩 따로 보관 · 폰·카드에서 멀리.

전원 요약

배터리 7.4V(6.0~8.4V) → 퓨즈 3A → 스위치 → L298N +12V. L298N 5V 점퍼를 끼워 +5V 단자 → 브레드보드 5V 레일(470µF) → ESP32 5V · 초음파 VCC. KY-024는 ESP32 3V3 핀에서. GND는 L298N GND 단자 한 점. USB를 꽂을 때는 레일 → ESP32 5V 선(P5)을 뽑습니다.

5. 모터 제어

요약 — 1kHz PWM, 배터리 전압으로 최고 듀티를 자동 계산해 속도를 일정하게, 200ms 부드러운 가속, 방향을 바꿀 때 0을 거침.

L298N 방향표 (모터 1개)

EN (PWM)IN1IN2동작
듀티HIGHLOW정방향
듀티LOWHIGH역방향
255HIGHHIGH급정지 (brake) — 잡힘 · 비상 정지
0——힘 빼고 굴러감 (coast) — 평소 정지

방향 반전 설정(invertL/R)이 켜져 있으면 IN1·IN2를 서로 바꿔서 냅니다. 배선을 다시 하지 않아도 됩니다.

설정값

PWM            = 1000 Hz, 8 bit (0~255), 채널 0 = ENA, 1 = ENB  (LED는 채널 2~4, 5 kHz)
최고 듀티      = 255 × min(1, V_목표 ÷ (V_배터리 − V_강하))
                 V_목표 = 5.5 V (TT모터 정격 3~6 V 안), V_강하 = 2.0 V (L298N, 시험으로 보정)
                 예) 8.4 V → 219 (86%) · 7.4 V → 255 (100%) · 그 아래도 255
최소 듀티      = 차마다 시험으로 정해 NVS 저장 (기본 90). 이보다 작은 명령은 0으로
부드러운 가속  = 듀티 변화를 10 ms마다 최대 13씩 (0 → 255 약 200 ms)
방향 전환      = 부호가 바뀌면 먼저 0까지 줄인 뒤 반대로 올림
회전           = 탱크식 섞기: L = throttle + steer, R = throttle − steer (각각 −1~1로 자름)
전진 제한      = 추격차만: 앞 10 cm 이하면 전진 명령 × 0.4, 3 cm 이하면 전진 0 (후진·회전은 허용)

6. 전원 보호

요약 — L298N의 5V가 약하므로 ① 부드러운 가속으로 순간 전류를 줄이고 ② 배터리를 일찍 끊고 ③ 재부팅이 나면 원인을 남깁니다.
배터리 측정   = analogReadMilliVolts(34) 16회 평균 → 약 2초 이동평균, × 4.03 × 보정계수(NVS)
경고          = 6.8 V 미만 → LED 노랑 깜빡임 (7.0 V 이상이 되면 해제)
정지          = 6.4 V 미만이 3초 계속 → 모터 정지 + 고정 (스위치를 껐다 켜야 풀림)
재부팅 원인   = setup에서 esp_reset_reason() 출력. BROWNOUT이면 LED 보라 3회 깜빡임
                → "출발할 때 꺼진다"를 바로 알 수 있음. 브라운아웃 검출 기능은 끄지 않음
조종 끊김     = BLE 끊김 또는 0.5초 동안 새 명령 없음 → 그 차 정지 (게임은 계속)

7. 센서: 초음파 · 홀 센서

요약 — 초음파는 추격차만 쏘고 충돌 방지에 씁니다. 도주차는 KY-024로 "기준값에서 얼마나 벗어났나"를 보고, 정해 둔 값을 50ms 동안 계속 넘으면 잡힘입니다.

초음파 (추격차만)

측정 간격 60 ms · Trig 10 µs · 대기 최대 12 ms (약 2 m) · 거리 = µs ÷ 58
최근 3회 중 가운데 값 사용 (튀는 값 제거) · 미검출 = "앞이 비어 있음"

KY-024 (도주차만)

읽기       = GPIO36, ADC_11db, analogReadMilliVolts 32회 평균, 10 ms마다
기준값     = 켤 때 1초 평균 (자석 없는 곳에서 켜기). 대기 단계에서 변화량이 작을 때만
             천천히 따라감 (온도 변화 보정). 게임 중에는 고정
변화량     = |지금 값 − 기준값| (mV)  → N극·S극 모두 같은 방향으로 커짐
잡힘       = 변화량 ≥ 기준(NVS, 시험으로 "5 cm일 때 값"으로 정함)이 5회(50 ms) 연속
             · 게임 중일 때만 판정
GPIO36·39는 Wi-Fi/ADC를 쓸 때 디지털 입력으로 쓰면 짧은 잘못된 펄스가 생기는 알려진 문제가 있지만, 여기서는 아날로그로만 읽어서 해당하지 않습니다.

8. 게임 진행

요약 — 대기 → 카운트다운 3초 → 게임 중 → 게임 끝, START로 다시. 잡히면 도주차는 계속 정지, 추격차는 1초 정지.
[대기] ── 추격차 START ──▶ [카운트다운 3초] ──▶ [게임 중] ── 켜져 있는 도주차 모두 잡힘 ──▶ [게임 끝]
  ▲                                                                                      │
  └──────────────────────────────── 추격차 START ────────────────────────────────────────┘
단계추격차도주차LED
대기 (켠 직후)자유 주행자유 주행역할 색 천천히 깜빡임
카운트다운정지정지3·2·1 깜빡임
게임 중주행 + 전진 제한주행, 잡힘 판정 켜짐역할 색 켜짐
잡힌 순간급정지 → 1초 뒤 주행급정지 → 그 판 끝까지 정지잡힌 차 빨강
게임 끝정지정지추격차 무지개, 도주차 빨강
  • 역할 색: 추격차 흰색 · 도주차 1 초록 · 2 파랑 · 3 노랑.
  • "켜져 있는 도주차" = 최근 1초 안에 상태 알림을 보낸 도주차. 꺼진 차는 세지 않음.
  • START는 대기·게임 끝 단계에서만 받습니다 (게임 중 누름은 무시).
  • 추격차가 2초 동안 보이지 않으면 도주차는 대기로 돌아가 자유 주행합니다.

9. 무선 메시지 (ESP-NOW)

요약 — 모두에게 보내기(broadcast) 방식이라 짝 맺기가 필요 없습니다. 팀 표시 숫자로 다른 팀 메시지를 걸러 내고, 중요한 "잡힘"은 "받음"이 올 때까지 다시 보냅니다.
공통 머리  : 팀 표시(2바이트 고정값) · 종류 · 보낸 차 번호 · 판 번호
STATUS     : 4대 모두, 200 ms마다  — 역할, 단계, 잡힘 여부, 배터리(0.1 V 단위)
START      : 추격차, START 누를 때 — 새 판 번호 (같은 판 번호는 한 번만 처리), 300 ms 동안 50 ms마다 반복
CAUGHT     : 도주차, 잡힌 순간     — ACK가 올 때까지 50 ms마다 반복
ACK        : 추격차, CAUGHT 받으면 — 잡힌 차 번호, 판 번호
Wi-Fi STA 모드 · 채널 1 고정 · 다른 팀 표시 또는 다른 판 번호의 CAUGHT는 무시

broadcast에는 무선 칩 자체의 "받았음" 확인이 없어서, 위처럼 프로그램이 직접 ACK를 주고받습니다.

10. 차별 설정 (NVS)

요약 — USB 시리얼(점검 프로그램)로 한 번 넣으면 ESP32에 저장됩니다. 본 프로그램은 읽기만 합니다.

차 번호1~4차에 붙인 번호

11. 시험 계획

요약 — 구간마다 실물로 시험하고 통과해야 다음으로 갑니다. 컴파일 확인은 pio run -e <환경>.
  1. 배선 + 점검 프로그램 (L298N판): 배선 가이드 11단계 → p 배선 · m 방향 · n 최소 듀티 · d 데모 · s 전압 강하. 통과: 바퀴를 띄운 상태에서 출발·급정지 20회 동안 재부팅 0회.
  2. PWM 비교: 1kHz · 5kHz · 20kHz에서 최소 듀티와 L298N 온도(5분 주행)를 재서 하나로 정함.
  3. 홀 센서: h 메뉴로 자석 거리 1~8cm마다 변화량 기록 → 5cm 값을 기준으로. 통과: 5cm 이내 10/10 감지, 6cm 이상 0/10 감지, 모터를 돌려도 오감지 없음.
  4. Dabble 주행: 폰 4대로 각자 차 연결, 0.5초 끊김 정지 확인.
  5. 전진 제한: 추격차를 벽으로 최고 속도로 보내 부딪치지 않고 멈춤 10/10.
  6. 게임: 4대로 START → 잡힘 3회 → 끝 → 재시작. 잡힘에서 두 차가 함께 멈추는지 영상으로 확인(0.1초 안).

12. 아직 실물로 정할 것 · 범위 밖

요약 — 아래 값은 부품이 와야 정할 수 있어서, 기본값으로 시작하고 시험 뒤에 고칩니다.

실물로 정할 것

  • ENA·ENB 헤더 두 핀 중 입력 핀 (멀티미터 — 배선 가이드 8단계)
  • PWM 주파수, L298N 전압 강하 V_강하, 최소 듀티
  • 잡힘 기준 mV (자석 20×10mm 도착 후), 센서·자석 높이
  • 전진 제한 거리 10cm / 3cm가 3~5cm 잡힘 거리와 맞는지 (초음파 위치와 자석 위치 차이 반영)
  • Dabble 앱이 팀원 폰(iOS/Android)에서 ESP32와 연결되는지

범위 밖 (이번에 하지 않음)

  • 점수판·시간 제한·여러 판 기록
  • 자체 조종 앱 (Dabble 사용)
  • 도주차 초음파 사용 (부품은 달아 두되 발사하지 않음)
  • 무선 펌웨어 업데이트(OTA)
